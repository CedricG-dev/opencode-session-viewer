- (capability) CAP-1 = FR-1 Auto-Launch: plugin opens Dashboard in browser at opencode startup with no manual command; non-fatal server-start failure is logged
- (capability) CAP-2 = FR-2 List all sessions: Dashboard lists every Session created during the current opencode run (title, status, message count, last-activity), live-updated in place; no prior-invocation or other-project sessions
- (capability) CAP-3 = FR-3 Live updates via event stream: Dashboard subscribes to opencode /event stream, updates in place with no polling; shows a disconnected indicator and reconnects on stream drop
- (capability) CAP-4 = FR-4 Cost tracking: Dashboard shows per-session token/dollar cost plus a live aggregate total, always matching opencode own reported figures, never independently computed
- (capability) CAP-5 = FR-5 Configuration: users set port, bind address, and autoLaunch toggle via opencode.json; default bind 127.0.0.1, invalid/busy port fails gracefully without blocking opencode startup
- (constraint) Local-only: Session content and Cost data never leave the machine - no telemetry/analytics, no external calls beyond what opencode itself makes to providers
- (constraint) Localhost-only bind by default (127.0.0.1); non-default network binding requires explicit documented opt-in, since Session content can include sensitive project code
- (constraint) Session-derived content (titles, any message text) is untrusted for rendering - no unescaped HTML injection into the Dashboard
- (constraint) No authentication for MVP given localhost-only default; becomes load-bearing before bind address is ever defaulted to non-localhost
- (constraint) Cost figures must never be computed independently of opencode own reporting - protects against pricing drift when providers change rates
- (constraint) Scope is single project, single opencode server instance, current run only - no cross-project/cross-instance aggregation, no historical session store from prior invocations
- (note) Non-goals sourced from PRD sec5.1 Never: no full transcript/conversation view, no cross-project fleet manager, no billing/export tool, no remote/multi-user dashboard, no general task-tracking tool, no independent cost recompute/cache/override, no telemetry ever
